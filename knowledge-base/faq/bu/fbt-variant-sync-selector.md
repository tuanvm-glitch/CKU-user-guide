# FBT Variant Sync Selector

⚠️ Problem/ Request:

Cần sync lựa chọn màu (color selection)/variant giữa theme và FBT

➡️ Support flow:

Selector class hoặc id của variant picket từ vần values tới options
.variant-picker__option-values .variant-picker__option

Cái này lấy từ div chứa các input(có theme sẽ là button || select) có các value là các option.

Thường sẽ là các div có class như nhau, chỉ khác nhau cái input ở trong từng div đó.
